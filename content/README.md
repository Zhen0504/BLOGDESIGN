# 内容维护

正文放在 development 或 research 下，每篇一个 Markdown 文件。图片放在 public/blog/文章英文名称/images，公开附件放在同级 attachments。

图片写法：`![图片描述](/blog/文章英文名称/images/example.png)`，不要使用本机路径。

元数据必填 title、date（YYYY-MM-DD）、summary、tags（数组）；cover 可选。本次日期为整理日期，不是实验日期。

公式支持 `$...$` 和 `$$...$$`。原始统计表附件是 Markdown 文件。训练脚本与原始数据不默认公开。
