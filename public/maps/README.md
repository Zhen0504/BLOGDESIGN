# Local land map

Source: Natural Earth, 1:50m physical land polygons (ne_50m_land).
Downloaded from https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/ — public domain.

world-land.svg is generated by `node tools/build-land-map.mjs` using an equirectangular projection. Only physical land outlines are displayed, not administrative or disputed borders. This is a small-scale personal location illustration, not a navigation map. Dalian coordinates: 121.614 E, 38.914 N. IP location is not connected.
