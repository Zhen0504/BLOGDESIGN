# Local land map

Source: Natural Earth, 1:50m physical land polygons (ne_50m_land).
Downloaded from https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_50m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/ — public domain.

world-land.svg is generated by `node tools/build-land-map.mjs` using an equirectangular projection. This is a small-scale personal location illustration, not a navigation map. Dalian coordinates: 121.614 E, 38.914 N.

Administrative reference layers use Natural Earth `ne_50m_admin_0_boundary_lines_land` and `ne_50m_admin_1_states_provinces_lines`, from the same public-domain repository. Run `node tools/build-map-borders.mjs` to generate world-borders.svg and province-borders.svg. Internal boundaries are available for the large countries represented in the 50m dataset, including China. Lines are generalized, illustrative, and do not constitute an authoritative territorial statement.

At zoom below 4x, only land and country boundaries appear. At 4x and above, internal boundaries and a sparse set of visible city labels appear; labels avoid foreground visitor/home pins. IP location is approximate and is queried only through this site's API.
