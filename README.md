# Leo Team Blog

Leo Team Blog 是一个基于 Vue 3 和 Vite 开发的团队博客网站，用于记录课程学习、前端实践、项目展示、团队协作和阶段性复盘。项目采用组件化方式组织页面与公共布局，当前已完成首页、博客列表、项目展示、团队介绍和关于页面的基础结构。

## 项目特点

- 使用 Vue 3 作为前端框架，配合 Vite 完成快速开发和生产构建。
- 使用 Vue Router 管理首页、博客、项目、团队、关于等页面路由。
- 首页包含粒子背景、标题交互、预览卡片等视觉效果。
- 博客列表通过本地数据文件维护文章内容，便于后续扩展为文章详情或接口数据。
- 页面样式拆分为重置样式、主题变量和全局样式，方便统一维护。
- 提供结构测试脚本，用于检查项目关键文件、依赖和页面结构是否完整。

## 技术栈

- Vue 3
- Vue Router 4
- Vite 6
- OGL
- Node.js

## 页面模块

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 首页 | 展示网站首屏、交互标题和内容入口 |
| `/blog` | 博客文章 | 展示技术文章、项目复盘和内容预告 |
| `/projects` | 项目展示 | 展示团队项目与阶段性成果 |
| `/team` | 团队成员 | 介绍团队成员和协作信息 |
| `/about` | 关于我们 | 说明博客定位、记录内容和后续计划 |

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

启动后根据终端提示访问本地地址，通常为：

```text
http://localhost:5173/
```

### 3. 生产构建

```bash
npm run build
```

构建产物会生成到 `dist/` 目录。

### 4. 预览构建结果

```bash
npm run preview
```

### 5. 运行结构测试

```bash
npm run test:structure
```

该脚本会检查关键项目文件、路由、布局组件、首页交互、关于页面结构和主题样式等内容，适合在提交前进行基础验证。

## 数据维护

博客文章数据位于：

```text
src/data/posts.js
```

导航菜单数据位于：

```text
src/data/navigation.js
```

后续如果需要新增文章、调整导航或扩展页面内容，优先修改对应的数据文件和视图组件，避免在多个组件中重复维护相同信息。
