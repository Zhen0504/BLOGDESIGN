# ZHEN 首帧闪现修复设计

## 目标

首次进入网站时，ZHEN 必须直接从未绘制状态开始线条动画，不允许在动画启动前短暂显示完整字样。

## 范围

- 仅调整共享线条字标组件的首帧样式。
- 保持现有 ZHEN 动画时长、配色、字形、说明文字和退出时序不变。
- 保持 LOADING 行为不变，不增加测试入口。

## 实现设计

`LineWordmark` 的 SVG 路径基础状态默认使用不可见的虚线参数，而不是依赖 Vue 写入 `data-animation="once"` 后才隐藏。动画模式继续从该隐藏状态开始描线；静态模式明确覆盖为完整路径。

这样即使组件挂载、样式匹配或动画初始化之间存在一个浏览器绘制帧，基础路径也不会提前显示。

## 验收标准

- 新标签页首次进入时，首张可见画面没有完整 ZHEN 闪帧。
- ZHEN 从空白状态直接开始描线并正常完成。
- 同标签页刷新仍跳过 ZHEN。
- LOADING 和 00–04 页面切换行为不变。
- 结构测试、生产构建和浏览器控制台检查通过。
