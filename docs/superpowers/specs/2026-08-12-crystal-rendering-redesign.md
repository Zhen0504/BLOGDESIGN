# 晶体实时视觉重构规范

日期：2026-08-12

目标分支：`codex/personal-portfolio-redesign`

状态：设计方向已由用户授权按最终效果优先推进

## 1. 决策

停止继续调整现有 Blender v2 材质。旧脚本、旧渲染图和旧规范全部保留为失败对照，不删除、不覆盖，也不导出为正式网站资产。

新的正式路线为：

1. Blender 或等效曲线工具只负责可控的分层几何。
2. Three.js 负责浏览器中的透射、折射、刻痕和交互。
3. `img2threejs` 的分阶段重建与截图对比方法只作为质量门禁，不把它当作一键生成器。
4. 静态 PNG 和交互视频是主要验收材料，实时网页是最终效果与性能的验证环境。

最终判断标准不是采用了哪种工具，而是浏览器中的实际效果是否达到本规范的视觉、交互和性能要求。

## 2. 第一阶段范围

第一阶段只重建 01「个人简介」晶体，不制作另外三颗晶体，不接入正式章节轮换，也不部署网站。

阶段输出是一颗在独立浏览器实验场景中真实运行的晶体，包括：

- 正面和三分之四视角的实际浏览器渲染。
- 小幅鼠标视差与旋转。
- 外壳、内环、内层面板及刻痕图标。
- 必要的边缘高光、色散、Bloom 和色调映射。
- 桌面与移动端性能记录。

用户通过这颗晶体后，才允许扩展另外三种轮廓并接入完整网站。

## 3. 参考图的结构解释

目标晶体不得再用两块封闭的深蓝色实体相互嵌套。必须拆成至少四个独立视觉层：

1. **外部透明厚边框**：接近无色，承担主要折射和细窄轮廓高光。
2. **内侧透明凹环**：与外框保持可见间隙，形成第二道折射边界。
3. **深色中央面板**：深海军蓝紫色，仍保留有限透光，不是纯黑或不透明塑料。
4. **内层刻痕图标**：贴合中央面板曲面，通过蒙版控制法线、粗糙度和边缘散射。

少量蓝紫光和暖金闪点属于独立的艺术化高光层，不能通过把整个外壳染蓝或提高整体自发光来模拟。

## 4. 几何方案

### 4.1 外形

- 继续采用柔性三瓣盾形，但重新绘制轮廓。
- 正面是带倒角的扁平晶体徽章，不是充气球体。
- 四颗晶体最终使用不同的非对称轮廓，不能简单旋转或等比缩放同一个模型。

### 4.2 分层

- 外框、内环和中央面板分别建模、分别命名、分别绑定材质。
- 各层之间保留真实空间间隙，斜视时必须出现可观察的视差。
- 外框优先使用环形实体结构，避免一整块封闭玻璃把中央区域再次染成蓝色。
- 生产网格只承担轮廓、厚度、倒角和稳定法线；灯光、Bloom 和银河粒子不烘焙进模型。

### 4.3 资产职责

- GLB：分层网格、UV、法线和稳定节点名称。
- SDF 图标：可替换的非彩色蒙版。
- HDR 或反射纹理：随项目本地部署，不引用运行时外部 CDN。
- 网页材质：在 Three.js 中重新绑定，不依赖 Blender 节点图直接转换。

## 5. 实时渲染架构

正式运行时使用 Three.js WebGL 渲染，不再继续扩展旧 OGL 原型。

### 5.1 外框与内环

先以 `@pmndrs/vanilla` 的 `MeshTransmissionMaterial` 建立视觉基线，使用厚度、折射率、色散、各向异性模糊和轻微扰动。若基线无法达到目标，则只扩展透射片段，形成项目自己的 `GemTransmissionMaterial`，不从零重写整套渲染器。

外框需要采样场景离屏颜色缓冲，使银河、星尘、内层面板和其他必要物体能够通过外框产生折射，而不是简单透明叠加。

### 5.2 中央面板

中央面板使用较低透射、较高吸收的深蓝紫物理材质。其亮度来自环境反射、折射和局部高光，不使用大面积固定自发光。

### 5.3 图标刻痕

图标 SDF 同时控制：

- 朝内的浅凹法线。
- 凹槽内部的轻微暗化。
- 边缘粗糙度与冷白散射。
- 随观察角度变化的弱高光。

图标不得作为悬浮 DOM、白色贴纸、独立霓虹线或外凸几何呈现。

### 5.4 后期合成

使用高精度中间缓冲完成：

- 选择性 Bloom，只处理刻痕边缘和少量晶体闪点。
- 色调映射，避免白色高光溢出成大片色块。
- 景深，突出当前章节晶体并虚化其余晶体。
- 克制的暗角和色彩调整，保持深海军蓝背景层次。

## 6. 交互约束

- 鼠标只驱动小幅位置、旋转和内外层相对视差，不改变晶体基本轮廓。
- 正常阅读状态下晶体运动应平缓，停止输入后自然回正。
- 当前晶体保持清晰和高质量透射；非当前晶体缩小、变暗并进入景深范围。
- 后续 00–04 切换仍采用同一持续存在的三维场景和轨道换位，不重建五个页面或五个 Canvas。
- `prefers-reduced-motion` 和低性能设备允许降低运动、采样和 Bloom，但不能降级成不透明蓝色塑料块。

## 7. 性能与中国大陆访问

- 所有依赖、模型、纹理和环境图随站点静态资源部署，不在运行时调用境外 API 或第三方 CDN。
- 只有当前突出晶体启用高质量透射；背景晶体使用共享缓冲或简化材质，禁止四颗晶体各自执行完整高分辨率额外场景通道。
- 桌面目标为稳定 55–60 FPS；主流移动设备目标不低于 40 FPS。
- 自适应限制设备像素比，移动端降低透射缓冲分辨率、采样数、色散和景深质量。
- WebGL 初始化失败时保留完整 DOM 内容、深色背景和静态晶体海报，不影响导航与联系方式。

## 8. 验收与展示方式

每一轮必须同时交付：

1. 正面浏览器截图。
2. 三分之四视角浏览器截图。
3. 鼠标视差与缓慢旋转的视频或可重复浏览器录屏。
4. 与目标参考图并排的对照图。
5. 桌面和移动端帧率、控制台错误及资源大小记录。

PNG 和视频直接以文件形式展示，不依赖临时 localhost 验收页面。实时页面只负责验证鼠标交互、真实折射和性能。每张验收图在展示前必须确认文件存在、尺寸正常并能由图像查看器打开。

## 9. 单颗晶体通过条件

必须同时满足：

1. 第一眼是透明光学玻璃或宝石，而不是塑料、果冻或深蓝色胶块。
2. 能清楚识别外框、内环、中央面板和刻痕四层结构。
3. 深色背景与星尘能够透过外框并产生受控折射。
4. 轮廓扁平、圆润、不规则，侧视不鼓胀。
5. 图标像刻在中央面板表面，并随视角改变高光。
6. 高光主要是细窄冷白和蓝紫线，仅有极少暖金闪点。
7. 鼠标运动时内外层存在轻微视差，但图标不会脱离承载面。
8. 浏览器截图而非 Blender 静帧达到视觉要求。
9. 桌面和移动端达到性能目标，且控制台无错误。

任一条件失败都只返工这一颗晶体，不扩展另外三颗，也不接入正式页面。

## 10. 明确不采用

- 不以旧 Blender v2 为基础继续堆叠发光或提高透明度。
- 不把复杂 Blender 材质节点当作网页最终材质。
- 不使用图片贴在平面上冒充三维晶体。
- 不使用预渲染视频代替最终鼠标视差和章节轮换。
- 不把 `img2threejs` 当作自动生成高质量宝石的黑盒。
- 不优先采用依赖高成本 BVH 多次反弹的钻石折射方案。
- 不在单颗晶体未通过前制作其余三个模型。
