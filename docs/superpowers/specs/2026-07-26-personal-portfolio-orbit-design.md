# 个人作品集网站「Orbit Archive」设计规范

日期：2026-07-26  
目标分支：`codex/personal-portfolio-redesign`  
旧站备份：`archive/team-blog` / `legacy-team-blog-v1`

## 1. 项目目标

把现有 Vue 3 + Vite 团队博客重构为个人作品集网站。网站以作品展示为主，内容保持克制，重点呈现个人简介、开发项目、科研项目和联系方式。

核心体验是一套贯穿全站的 3D 晶体轨道：

- 四颗晶体分别代表个人简介、开发项目、科研项目和联系方式。
- 四颗晶体始终存在于同一个场景中，由银河状粒子云持续连接。
- 用户滚动或点击导航时，整套轨道旋转并交换晶体的前后与左右位置。
- 当前章节对应的晶体清晰、明亮且靠近前景；其余三颗降低亮度、缩小并虚化。
- 每颗晶体都随鼠标产生幅度很小的独立视差和姿态变化。

本次重构不延续旧站页面设计和旧站内容。旧站只通过备份分支保留。

### 2.1 色彩与材质

- 背景：接近黑色的深海军蓝，允许极弱的径向蓝紫光晕。
- 晶体：半透明深蓝紫玻璃，边缘带冷白或淡紫高光。
- 粒子云：蓝紫为主，少量暖金色星点。
- 正文：暖白或低饱和银灰。
- 强调色：只使用少量暖金色，主要用于章节编号、当前状态点和微小高光。
- 不使用高饱和大色块、霓虹渐变按钮或彩色中文标题。

### 2.2 字体

- 英文大标题：高对比度衬线字体，气质接近现代编辑设计。
- 英文界面文字：字距略大的简洁无衬线字体。
- 中文标题与短句：宋体或仿宋气质的衬线字体。
- 推荐中文字体栈：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", "STSong", "SimSun", serif`。
- 中文颜色统一为暖白或银灰，不使用亮黄色。
- 全站最多使用两套主字体体系：衬线标题体系与无衬线界面体系。

## 3. 页面状态与固定构图

网站是一个包含五个全屏状态的单页体验。编号和左右位置不可互换。

### 00：Orbit Archive 总览

- 左侧显示英文标题 `Orbit Archive.`。
- 副标题只显示英文：`ABOUT · DEVELOPMENT · RESEARCH · CONTACT`。
- 00 页面不出现中文。
- 四颗晶体都清晰可见，尺寸和视觉权重接近。
- 四颗晶体围绕中央小型切面晶体分布。
- 银河状粒子云完整连接四颗晶体。

### 01：个人简介

- 当前晶体：人物轮廓图标。
- 当前晶体固定在右侧前景。
- 内容固定在左侧。
- 其余三颗晶体保留在背景并明显虚化。
- 内容只包含章节标识、`个人简介` 标题、一句简介和最多三个关键词。
- 不放置长篇自传、时间线或技能进度条。

### 02：开发项目

- 当前晶体：`</>` 极简线性图标。
- 当前晶体固定在左侧前景。
- 内容固定在右侧。
- 其余三颗晶体保留在背景并明显虚化。
- 只展示两个最新开发项目。
- 每个项目入口保持短小，约 300–340 px 宽、66–76 px 高。
- 项目入口只包含序号、项目名、技术或类型短标签和箭头。
- 不使用长横条、大型卡片或项目详情段落。

### 03：科研项目

- 当前晶体：单一轨道或原子线性图标。
- 当前晶体固定在右侧前景。
- 内容固定在左侧。
- 其余三颗晶体保留在背景并明显虚化。
- 只展示两个最新科研项目。
- 项目入口尺寸和密度与开发项目保持一致。
- 不出现第二个 Research 栏目，不使用书本或烧瓶替代科研图标。

### 04：联系方式

- 当前晶体：信封线性图标。
- 当前晶体固定在左侧前景。
- 内容固定在右侧。
- 其余三颗晶体保留在背景并明显虚化。
- 内容只展示一句邀请语和实际可用的联系方式。
- 第一版至少提供 GitHub；电子邮件未配置时隐藏该行，不显示虚假邮箱。
- 不实现联系表单，不引入后端。

## 4. 交互与动效

### 4.1 章节切换

- 鼠标滚轮、触控滚动、键盘方向键和顶部导航都可以切换章节。
- 切换时不更换整张页面，也不把晶体展开成内容面板。
- 固定的 3D 场景持续存在，只有轨道、晶体位置、景深、亮度和内容层发生过渡。
- 默认过渡时长控制在 900–1300 ms。
- 同一次过渡期间锁定重复切换，避免滚轮连续触发跳过章节。
- 切换完成后更新右侧编号和状态点。
- 顶部导航点击后直接进入对应状态，并保持相同的 3D 轮换动画。

### 4.2 晶体鼠标响应

- 鼠标移动只产生轻微视差，不允许晶体追随鼠标大幅漂移。
- 单颗晶体的旋转建议限制在约 `±3°`，位移限制在约 `±12 px`。
- 当前晶体响应稍明显；背景晶体响应更弱。
- 鼠标离开后平滑回到章节预设姿态。

### 4.3 银河粒子连接

- 粒子云是连续、柔软、具有体积感的连接带，不是简单的几条几何轨道线。
- 粒子云随晶体位置变化而变形，并在过渡过程中保持连贯。
- 粒子密度集中在晶体附近和连接路径上，背景只保留稀疏星尘。
- 粒子不能遮挡标题和项目入口的可读性。

### 4.4 项目入口

- 开发项目和科研项目各显示两个最新条目。
- 悬停时只允许边框、高光、箭头位移和极轻微背景亮度变化。
- 点击项目可以打开内部详情路由或外部链接；数据中未配置目标时按钮保持不可点击，不制造空白页面。
- 键盘聚焦样式必须清晰可见。

## 5. 技术架构

继续使用现有 Vue 3、Vue Router、Vite 和 OGL，不引入 WordPress、数据库或公开管理后台。

采用“固定 WebGL 场景 + DOM 内容层”的混合结构：

1. OGL 负责四颗晶体、中央晶体、银河粒子云、相机和鼠标视差。
2. Vue DOM 层负责标题、项目入口、导航、状态指示器和可访问性。
3. 一个统一的章节状态配置同时驱动 3D 场景和 DOM 内容，防止两者不同步。
4. 页面切换由单一状态机控制，不为五个章节分别创建互不关联的 3D 场景。

建议模块边界：

- `src/components/orbit/OrbitScene.vue`：Canvas 生命周期、渲染循环和尺寸管理。
- `src/components/orbit/CrystalMesh.js`：晶体几何、材质、图标纹理与状态插值。
- `src/components/orbit/ParticleGalaxy.js`：粒子生成、连接路径和性能降级。
- `src/components/orbit/orbitStates.js`：00–04 的位置、旋转、缩放、清晰度和相机参数。
- `src/components/layout/PortfolioHeader.vue`：品牌文字和章节导航。
- `src/components/layout/SectionIndicator.vue`：右侧编号与五个状态点。
- `src/components/sections/SectionContent.vue`：章节内容的通用过渡容器。
- `src/components/projects/CompactProjectLink.vue`：开发和科研共用的紧凑项目入口。
- `src/data/portfolio.js`：简介、项目、联系方式和外部链接的唯一数据源。
- `src/composables/useSectionNavigation.js`：滚轮、键盘、触控和导航切换。
- `src/composables/useReducedMotion.js`：动效偏好与降级策略。

## 6. 数据结构

`src/data/portfolio.js` 至少包含：

- `profile`：姓名或品牌、简介、关键词。
- `developmentProjects`：按日期降序排列的开发项目，页面取前两个。
- `researchProjects`：按日期降序排列的科研项目，页面取前两个。
- `contact`：GitHub、可选邮箱和其他明确提供的链接。

项目条目至少包含：

- `title`
- `label`
- `year`
- `href`
- `external`

没有真实链接的条目可以用于视觉占位，但必须呈现为不可点击状态，不能指向 `#`。

## 7. 响应式与无障碍

### 桌面端

- 设计基准为 16:9 桌面视口。
- 01/03 保持内容左、晶体右；02/04 保持晶体左、内容右。
- 内容宽度受到限制，不能侵入晶体的主要视觉区域。

### 移动端

- 保留章节顺序和当前晶体突出逻辑。
- 内容位于上半区，晶体轨道位于下半区或背景中，不强行保持桌面左右构图。
- 降低粒子数量、设备像素比和晶体网格细分。
- 项目入口宽度适配容器，但仍保持短内容和两条上限。

### 无障碍

- Canvas 标记为装饰性；所有实际信息必须存在于 DOM。
- 导航和项目入口支持键盘操作。
- 当前章节通过可读文本和 `aria-current` 表达，不能只依赖颜色。
- 尊重 `prefers-reduced-motion`：关闭鼠标视差，缩短切换，降低或停止粒子运动。
- 文本与背景满足可读对比度。

## 8. 性能与降级

- 桌面端设备像素比上限建议为 1.5–2；移动端更低。
- 页面不可见时暂停渲染循环。
- 根据设备能力降低粒子数量和晶体细分。
- WebGL 初始化失败时显示静态深色背景、简化晶体图像或纯 DOM 内容，导航和项目链接仍可使用。
- 首屏不得等待全部非关键资源加载后才显示文字。
- 目标是常见桌面设备保持平滑交互，移动设备不因特效过热或明显掉帧。

## 9. 安全与部署约束

- 网站保持纯静态架构，无数据库、无登录、无公开后台。
- 外部链接使用 `rel="noopener noreferrer"`。
- 不在前端代码中保存密钥、令牌或隐私信息。
- 不实现直接发送邮件的前端表单。
- 构建产物能够部署到面向中国大陆稳定访问的静态托管或对象存储/CDN。
- 部署、域名、备案和 CDN 配置不属于第一阶段编码范围。

## 10. 测试与验收标准

### 功能

- 00–04 顺序准确，不能出现两个 Research。
- 滚轮、键盘、触控和顶部导航都能到达全部状态。
- 01/03 当前晶体在右，02/04 当前晶体在左。
- 开发和科研各只显示两个最新项目。
- 返回 00 后四颗晶体恢复近似相同的清晰度和视觉权重。

### 视觉

- 当前晶体明显清晰、明亮；其他三颗明显虚化、变暗、退后。
- 四颗晶体始终存在并由银河粒子云连续连接。
- 00 页面不出现中文。
- 中文使用宋体或仿宋气质字体，并保持暖白或银灰颜色。
- 项目入口短小，不出现长横条和大型详情面板。

### 质量

- `npm run build` 成功。
- 现有或更新后的结构测试通过。
- 桌面和移动端没有横向溢出。
- 减少动态效果模式可用。
- WebGL 不可用时核心内容和导航仍可访问。

## 11. 实施边界

第一阶段完成：

- 00–04 单页体验。
- 四晶体轨道和银河粒子连接。
- 章节切换、当前晶体聚焦、背景虚化和鼠标轻微视差。
- 两组紧凑项目入口。
- 响应式、减少动态效果和 WebGL 降级。

第一阶段不完成：

- WordPress 或其他 CMS。
- 在线管理后台。
- 联系表单和服务端邮件发送。
- 用户账户、评论、数据库。
- 复杂项目详情编辑系统。
- 正式部署、域名购买和备案。
