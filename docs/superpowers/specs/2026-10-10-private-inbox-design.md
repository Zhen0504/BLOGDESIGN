# 私有建议箱（用户已确认）

保持现有建议卡片和粒子笑脸外观，启用真实提交。SQLite 在私有目录保存正文、UTC 时间和随机 ID。Python 标准库后端监听本机，由现有 HTTPS Nginx 转发；无需新增外部端口、Node 运行时或数据库服务。

仅站长通过本机 CLI 查看、导出与备份。无网页管理后台，无公开查询留言 API。现有公开建议面板继续为空并说明审核发布尚未开放。

限制正文 1～1000 字；同来源每分钟一次、每天二十次，全站每天一千次。来源只保存 keyed HMAC 限流指纹，二十四小时清理。校验 Origin 和 JSON，请求最大八千字节，隐藏字段基础拦截机器人。UUID 提交标识提供二十四小时重试幂等性。限流不是完整 CAPTCHA/抗 DDoS 方案。

前端仅在数据库事务提交后显示成功，网络失败保持输入及提交标识。Nginx 覆盖来源头，服务仅接受回环连接；数据库不置于 webroot。systemd 以独立低权限用户运行。部署备份现有配置并通过 nginx -t 后重载。单元和 HTTP 集成测试覆盖真实写入、失败、重复、并发、来源和私有性；生产构建验证前端编译。

本轮先完成建议箱，访客地图定位另作后续实施，需要选择可用本地 IP 数据库并核实许可与精度。现有 SSL、备案、网站路由保留。未经成功远程验证不宣称已上线。
